# DES 加密算法实现（纯 C）

河北地质大学 · 信息工程学院 · 密码学课程实验 2

不依赖任何第三方库、按 FIPS 46-3 置换表从零实现的经典 DES，支持任意长度明文的加密与解密。

## 实现要点

- 完整实现 16 轮 Feistel 结构：IP / IP⁻¹ 初始与末尾置换、PC-1 / PC-2 密钥置换、E 扩展置换、8 个 S 盒、P 置换
- 密钥调度：56 位有效密钥 + 16 轮循环左移
- 分组模式：ECB
- 明文长度不限：用 **PKCS#7 填充**补齐到 8 字节的整数倍，也可用 `-n` 关闭填充
- 明文既可以是字符串（按 UTF-8 编码），也可以是十六进制串，因此中文和任意二进制数据都能处理
- `-v` 打印每轮 L、R 中间值，便于对照教材逐轮核对
- Windows 下自动把控制台代码页切到 UTF-8，中文输出不乱码

## 编译运行

```bash
gcc -Wall -Wextra -O2 des.c -o des
```

```bash
./des                                # 交互模式（1 加密 / 2 解密 / 0 退出）
./des -e <密钥> <明文>                 # 加密字符串，输出密文 HEX
./des -e <密钥> -x <十六进制明文>       # 加密十六进制明文
./des -d <密钥> <十六进制密文>          # 解密
```

密钥可以是 8 个字符，也可以是 16 位十六进制串。附加 `-n` 表示不填充（此时长度必须是 8 的整数倍，否则会给出明确报错），附加 `-v` 打印每轮 L、R。

## 实际运行效果

加密字符串：

```
$ ./des -e 12345678 hello
密钥 K = 3132333435363738（按 8 字节字符串解释）
明文字节数 = 5，密文分组数 = 1
密文(HEX) = BA16C6A0257125AF
```

加密十六进制明文：

```
$ ./des -e 3132333461626364 -x 4E6F7720697320746865
密钥 K = 3132333461626364（按十六进制解释）
明文字节数 = 10，密文分组数 = 2
密文(HEX) = 9537EACB9FBE2DB30E21392C18E80C1A
```

打印逐轮中间值（`-v`）：

```
$ ./des -e 12345678 -v hello
 【第 1 个分组】
  L(0)  = 1F001EF2
  R(0)  = 001F1DF0
  第 1轮: L = 001F1DF0  R = 3577F4FA
  第 2轮: L = 3577F4FA  R = A9EB2F95
  ...
```

## 正确性验证

`验证结果.txt` 中记录了本程序与标准文档及两个独立实现的交叉验证：

- **FIPS PUB 81 表 B1**（ECB 示例，密钥 `0123456789abcdef`）
- **NIST SP 800-17 附录 B 表 1**（DES ECB 可变明文 KAT，密钥 `0101010101010101`）
- 与 **OpenSSL 3.5.7**、**PyCryptodome 3.23.0** 的输出逐条比对

所有测试向量结论均为「一致」，另外还记录了不填充模式下的逐轮中间值输出。
